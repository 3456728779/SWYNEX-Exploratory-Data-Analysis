# SWYNEX - Exploratory Data Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on a cleaned Blinkit dataset as part of the SWYNEX internship/task.

The analysis focuses on understanding sales patterns, product performance, customer ratings, delivery times, discounts, demand, and city-level sales.

## Dataset

The dataset contains Blinkit product and sales information, including:

- Product details
- Category
- Price and discount
- Ratings
- Reviews
- Delivery time
- City
- Stock
- Sold quantity
- Profit margin
- Demand index
- Dates
- Delivery status

## EDA Performed

The following analyses were performed:

1. Dataset overview
2. Missing value analysis
3. Duplicate record analysis
4. Statistical analysis
5. Sales analysis by category
6. Sales analysis by city
7. Product rating analysis
8. Discount and sales analysis
9. Delivery time analysis
10. Top 10 best-selling products
11. Stock and demand analysis
12. Key EDA insights

## Key Results

- Average Price: 267.30
- Average Final Price: 240.74
- Average Rating: 4.20
- Average Delivery Time: 27.56 minutes
- Total Sold Quantity: 2,111,201
- Average Profit Margin: 22.65%
